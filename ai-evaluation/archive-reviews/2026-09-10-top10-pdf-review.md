The scope starts with all 231 citation occurrences attached to 190 ranked techniques in the 19 finalized year collections (including the combined 2016–17 collection). Source provenance identified the PDF-derived documents for page-by-page review. HTML captures with generated PDFs are outside this transcription comparison.

Windows Docker rendered original PDF pages to images for visual inspection. Full source text and the previous Markdown were compared with those images. Repairs restore reading order, headings, tables, code, payload characters, captions and diagram relationships. Actual code remains fenced code. Relational diagrams become Mermaid where their meaning can be represented faithfully; screenshots, plots and visual evidence retain source crops. Obscured or illegible source details are explicitly identified rather than guessed.

Published frontmatter was checked against curated titles, authors, publishers and dates. Each published body contains the complete staged transcription; every local figure exists. Original PDF hashes match the stored source. The XXE slides, XSLT whitepaper and recovered Modern Web Technologies deck are intentional exceptions to retaining the previous published PDF: complete original publisher PDFs replaced incomplete generated copies.
