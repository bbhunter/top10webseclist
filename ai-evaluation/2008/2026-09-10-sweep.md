## Survivor: Lateral SQL Injection

- Original author and source: David Litchfield / NGSSoftware,
  <https://www.davidlitchfield.com/lateral-sql-injection.pdf>.
- Source read: all four pages through the web PDF reader. The cover says
  **27 February 2008**. The [Black Hat DC archive](https://blackhat.com/html/bh-dc-08/bh-dc-08-archives.html)
  lists Litchfield's *Oracle Security* talk, but its recovered listing alone
  does not establish precisely which technical detail was presented.
- Date precision: do not equate manuscript date with public availability.
  [Pete Finnigan's contemporary account](https://www.petefinnigan.com/weblog/archives/archive-042008.html)
  dated 30 April says he read it privately in February and the paper had been
  released the preceding week. This is a discovery pointer for publication
  timing; the original PDF establishes the work/version and the 2008 year.
  Treat the public cutoff as an unresolved February–April 2008 interval until
  contemporary release evidence resolves it.
- Technical residue: implicit conversion from DATE to SQL text is influenced by
  the caller's session formatting. A procedure taking a DATE, or even no
  arguments and using SYSDATE, can concatenate injected SQL after an attacker
  controls NLS_DATE_FORMAT. DATE examples demonstrate execution through
  DBMS_SQL.EXECUTE; NUMBER/NLS_NUMERIC_CHARACTERS demonstrates a quote/error,
  with exploitability expressly limited. Do not import the completed NUMBER
  exploit from the author's 2012 *Lateral SQL Injection Revisited* paper.
- Preliminary novelty comparison: [Cursor Injection](https://www.davidlitchfield.com/cursor-injection.pdf),
  author cover **24 February 2007**, was fetched. It supplies the precompiled
  cursor execution stage through an existing injectable string parameter.
  The candidate's separately testable contribution is how a typed/no-argument
  procedure becomes injectable via its ambient formatting state. Cursor-based
  privilege escalation is prior art and must not be scored again.
- Earlier citation still needing retrieval: cursor-snarfing.pdf from the same
  author host failed in the web reader. Mechanism searches of the full local
  archive for `nls_date_format`, `lateral sql injection`, `cursor snarfing`, and
  `cursor injection` returned no matches. This is absence from the local
  corpus, not proof of historical novelty.
- Plausibly clears the 55 gate as a meaningful extension, but **unscored**.
  Caveat: direct session influence is a significant prerequisite; judge the
  transferable audit insight, not presumed universal remote exploitation.
- Shell downloads failed due to restricted DNS. No local primary PDF/body was
  saved; the parent can retrieve the linked four-page source in the web reader.
